Expected CSV formats

First row must be the header; UTF-8 encoding

FileColumnsNotes
categories.csv name,type type is income or expense · existing names are skipped
budgets.csv category,monthly_limit matched by category name (spending categories only — savings buckets are skipped) · existing budgets are updated
transactions.csv date,type,category,amount,note[,owner] date as YYYY-MM-DD · unknown categories are auto-created · owner must be an existing user (else attributed to you)
